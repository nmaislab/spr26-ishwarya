# Draw.io Diagram Files

This folder contains editable draw.io / diagrams.net source files for the
AutoLLMCompose diagrams. Open the `.drawio` files in draw.io when you need to
edit the diagrams or export them for reports, slides, or documentation.

## Files

| File | Purpose |
| --- | --- |
| `1_local_exper4.drawio` | Local experimental environment diagram. |
| `2_layered_architecture4.drawio` | AutoLLMCompose layered architecture diagram. |
| `3_api_repo_prep2.drawio` | API repository preparation flow. |
| `4_runtime_swimlane.drawio` | Runtime swimlane / pipeline flow. |
| `5_strategy_comparison2.drawio` | Strategy comparison diagram. |
| `evaluation_pipeline_4.drawio` | Evaluation pipeline and four-mode comparison. |
| `topsis_qos_ranking_3.drawio` | TOPSIS QoS ranking process. |

## Open and Edit

1. Go to <https://app.diagrams.net/> or open the draw.io desktop app.
2. Choose **File > Open From > Device**.
3. Select the `.drawio` file you want to edit from this folder.
4. Make changes in draw.io.
5. Save the updated source with **File > Save** or **File > Save As**.

Keep the `.drawio` file as the main editable source. Exported images should be
treated as outputs, not replacements for the source file.

## Export for Use

Use **File > Export as** in draw.io:

- `PNG` for README files, slides, and quick previews.
- `SVG` for scalable diagrams in documents or web pages.
- `PDF` for thesis/report submissions.

When exporting, use a clear filename that matches the source diagram, for
example:

```text
2_layered_architecture4.png
2_layered_architecture4.pdf
```

## Notes

- If draw.io asks where to save changes, choose **Device** to update the local
  file.
- Avoid renaming source files unless the references in reports or slides are
  also updated.
- Commit the updated `.drawio` file whenever a diagram changes.
